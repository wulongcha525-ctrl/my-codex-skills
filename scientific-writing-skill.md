# Scientific Writing Skill

## Purpose

This skill helps me write, revise, and polish scientific manuscripts more efficiently.

## When to use

Use this skill when I need to write or improve a manuscript, abstract, cover letter, response letter, title page, ethics statement, data availability statement, or figure legend.

## Workflow

1. Clarify the manuscript type, target journal, and main research question.
2. Check whether the writing follows scientific logic: background, knowledge gap, objective, methods, results, interpretation, and conclusion.
3. Improve the language to make it clear, formal, concise, and suitable for SCI journals.
4. Keep terminology consistent throughout the manuscript.
5. Check whether the methods, results, figures, tables, and conclusions are logically connected.
6. Provide a polished English version and, when needed, a Chinese explanation for easier understanding.

## Output style

- Use formal academic English.
- Avoid exaggeration or unsupported claims.
- Keep the writing concise and journal-ready.
- Provide paste-ready text when possible.
- Explain important revisions in Chinese when needed.

## Example tasks

- Polish a manuscript paragraph.
- Write a cover letter.
- Write a response to reviewers or technical check comments.
- Improve figure legends.
- Rewrite the abstract.
- Prepare ethics and data availability statements.
